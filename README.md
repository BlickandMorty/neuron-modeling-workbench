## First experiment
Question: How does constant input current change firing in a leaky integrate-and-fire neuron?
Hypothesis: below 150 pA it remains silent; above that threshold it fires, with higher current producing higher rates.
Method: Brian2 with exact subthreshold integration; current sweep; 0.1 and 0.05 ms time steps; analytic firing-rate comparator.
Measure: spikes per second after discarding the first 500 ms.
Falsifier: firing below threshold or disagreement with the analytic rate beyond 2 Hz.
Stopping rule: run the fixed grid once; investigate numerical failures before extending it.
Results: `results/sweep.csv`, `checks.json`, and `neuron.png` are generated by `python neuron_lab.py`.
Boundary: a standard single-cell teaching model with illustrative parameters. It does not model a whole brain, consciousness, ion channels, or drug effects, and has not been fitted to recordings.

## Tools and where to use them
Python is the language. NumPy handles arrays; pandas handles tables; SciPy solves equations/fits parameters; matplotlib creates figures; Plotly creates interactive plots; SymPy manipulates equations; scikit-learn supplies baseline ML; Brian2 simulates neurons. DuckDB lets you run SQL directly over tables and CSVs. JupyterLab combines code, explanations, and results. VS Code edits longer scripts. Git tracks revisions.

Sources: [Brian2 neuron tutorial](https://brian2.readthedocs.io/en/stable/resources/tutorials/1-intro-to-brian-neurons.html), [Brian2 source](https://github.com/brian-team/brian2).
